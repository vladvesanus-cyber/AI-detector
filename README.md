# AI Text Detector

A simple NLP web application that predicts whether a given piece of text was written by a human or generated by AI. The model is trained on a labeled dataset of human and AI-generated essays using TF-IDF features and a Linear Support Vector Classifier, and served through a lightweight Flask web app.

## Features

- Train a text classification model from a CSV dataset
- Serialize the trained model and vectorizer for reuse
- Simple web UI to paste text and get an instant prediction
- Clear "Human" vs "AI-generated" result page

## Tech Stack

- **Python**
- **scikit-learn** — `TfidfVectorizer`, `LinearSVC`
- **pandas** — data loading and sampling
- **Flask** — web server and routing
- **Jinja2** (HTML templates) — rendering the UI

## Dataset

`Data/data.csv` contains two columns:

| Column      | Description                                      |
|-------------|---------------------------------------------------|
| `text`      | The text sample (essay/paragraph)                  |
| `generated` | Label — `1` if AI-generated, `0` if human-written  |

For training, a random sample of 30,000 rows is drawn from the full dataset (`random_state=42` for reproducibility) to keep training fast.

You can find it there: https://www.kaggle.com/datasets/shanegerami/ai-vs-human-text?resource=download

## How It Works

1. **Training (`main.py`)**
   - Loads `Data/data.csv` and samples 30,000 rows.
   - Converts text into numerical features using `TfidfVectorizer`.
   - Splits data into train/test sets (80/20).
   - Trains a `LinearSVC` classifier.
   - Saves the trained `model` and `vectorizer` together into `artifacts.pkl`.
   - Prints the model's accuracy on the test set.

2. **Serving (`app.py`)**
   - Loads `artifacts.pkl` on startup.
   - Exposes a home page (`/`) with a text input form.
   - On submission (`/check`), vectorizes the input text and predicts whether it's AI-generated or human-written.
   - Displays the result on a dedicated results page.

## Setup & Usage

### 1. Clone / unzip the project and navigate into it
```bash
cd NLP
```

### 2. Create a virtual environment (recommended)
```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Train the model
This generates `artifacts.pkl`, which is required for the app to run.
```bash
python main.py
```

### 5. Run the web app
```bash
python app.py
```

The app will start at `http://127.0.0.1:5000/`. Open it in your browser, paste in some text, and click **Check** to see the prediction.

## Notes & Possible Improvements

- The model is trained on a subset (30,000 rows) of the dataset for speed; using the full dataset may improve accuracy.
- `TfidfVectorizer` + `LinearSVC` is a fast, lightweight baseline. Performance could potentially be improved with:
  - N-gram features (`ngram_range`)
  - Other classifiers (Logistic Regression, Gradient Boosting)
  - Transformer-based embeddings (e.g., BERT) for higher accuracy at the cost of speed
- Add model evaluation metrics beyond accuracy (precision, recall, F1-score, confusion matrix).
- Add input validation and error handling on the Flask side for production use.
- Consider adding a `requirements.txt` pin (exact versions) for reproducible environments.
